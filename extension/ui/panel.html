Set up Ollama Free

Ollama runs AI models locally on your computer. No account needed, no data leaves your machine.

  1. Download and install Ollama ollama.com/download →
  2. Open a terminal and run this command:
    ollama pull minicpm-v:8b
    Downloads the AI model (~5 GB). Takes a few minutes on first run.
  3. Come back here when the download finishes, then click Test below.
